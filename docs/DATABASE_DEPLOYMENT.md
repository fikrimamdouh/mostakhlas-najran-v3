# تحديث مخطط قاعدة البيانات

بناء ونشر التطبيق لا يغيّر مخطط قاعدة البيانات تلقائيًا. هذا قرار مقصود لحماية
المستخدمين والمستخلصات والنسخ الاحتياطية من أي تغيير قسري غير مُراجع أثناء نشر
واجهة أو إصلاح عادي.

عند وجود تغيير مقصود في `lib/db/src/schema`:

1. راجع الفرق وتأكد أن التغيير لا يحذف جدولًا أو عمودًا أو بيانات قائمة.
2. أنشئ نسخة احتياطية إدارية كاملة وتحقق من عدد الصفوف قبل التغيير.
3. نفّذ `pnpm db:reviewed-push` في بيئة مراقبة وباستخدام قاعدة البيانات المقصودة.
4. تحقق من الجداول وعدد الصفوف، ثم انشر التطبيق.

يُمنع إضافة `push-force` إلى أمر بناء Vercel؛ تغييرات المخطط عملية مستقلة تحتاج
مراجعة ونسخة احتياطية وخطة رجوع.
